# AgenticAIExplore

A hands-on collection of small, independently understandable AI-engineering projects.

| Project | Focus |
| --- | --- |
| `1-structured-output-agent` | Producing validated structured output from an LLM. |
| `2-rag-agent-with-citation-grounding` | A reusable Confluence RAG pipeline with grounded answers, citations, two vector-store backends, and evaluation. |
| `3-multi-tool-orchestrator-agent` | Multi-tool agent orchestration experiments. |
| [**PatchPilot**](https://github.com/harshavardhan117/patchpilot) (project 4) | A LangGraph agent that finds CVEs in a Python dependency tree and proposes a pip-verified fix set, as a FastAPI + Celery + RabbitMQ service with a web page (Docker Compose, about 600 tests). **Now lives in its own repository: [harshavardhan117/patchpilot](https://github.com/harshavardhan117/patchpilot).** |

Projects 1 to 3 live in this repository. Each project has its own README, setup instructions, and local safety guidance. Never commit credentials, private source content, generated embeddings, database files, or evaluation data from internal systems.
